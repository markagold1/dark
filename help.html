QPlot makes if super-easy to prettify MATLAB and GNU Octave plots.

Step-by-step instructions

  1. Create plots as usual
  2. Enter qplot to launch the prettifier app
  3. Use Figure dropdown to select the figure number to to prettify
  4. Select your desired font from the Font dropdown
  5. Use the Title, XY, Ticks, and Legend dropdowns to size plot fonts
  6. Use the Bold and Italic checkboxes to set your desired font style (if the font supports it)
  7. Choose Dark or Hand to apply a theme, click Normal to revert to a standard light theme
  8. Click Update Figure List if you've opened or closed figures since launching QPlot
  9. Close QPlot by clicking the X in the upper right corner of the app window

Tips and Hints

  • When using GNU Octave, selecting figure number, font type, and size is most easily done by hovering your mouse cursor over the dropdown and using the mouse scroll wheel. Mouse clicking works but is not necessary.
  • With MATLAB, you must click the dropdown then scroll to find your selection.
  • QPlot is a GUI wrapper around font_adjuster.m, dark.m, undark.m, and hand.m.

Compatibility

  • QPlot has been tested on MATLAB versions R2025b and R2024b.
  • QPlot has been tested on GNU Octave versions 11.1, 10.1, 8.4, and 5.2.0.
  • QPlot has been tested on Windows 11, Ubuntu 24.04, and Red Hat RHEL 8.
